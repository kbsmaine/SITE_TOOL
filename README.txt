Important security note:
Host the site on HTTPS, not plain HTTP. Most modern hosts like Netlify, Vercel, Hostinger, Wix, Squarespace, GoDaddy, and cPanel hosts can enable a free SSL certificate. The audit request box now uses JavaScript to open an email draft instead of submitting an insecure form, but the website itself should still be published with HTTPS so visitors do not see browser security warnings.


UPDATE: The Free AI Audit form now uses FormSubmit's _next redirect. When the site is hosted on HTTPS, visitors are returned to the same page after submission with a success message instead of being left on FormSubmit's site.
